# juanevillam.com

My personal site: the apps I make, the work I do, and the events I've been to, narrated in my own voice.

Built with [Astro](https://astro.build) as a static site and deployed on Cloudflare Pages. Plain CSS and a little TypeScript, no UI framework.

## Run it

```bash
npm install
npm run dev
```

`npm run build` writes the static site to `dist/`.
